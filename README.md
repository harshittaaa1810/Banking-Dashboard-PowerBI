# 🏦 Banking Analytics Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing banking customer data and financial metrics to develop an interactive Banking Analytics Dashboard using Microsoft Power BI.

The dashboard is designed to provide insights into customer profiles, banking relationships, deposits, loans, savings, and other key financial indicators.

## 🎯 Project Objectives

* Analyze customer demographics and banking relationships.
* Monitor deposits, loans, and other financial metrics.
* Track key performance indicators (KPIs).
* Explore customer segmentation and financial trends.
* Present business insights through interactive visualizations.

## 🛠️ Tools & Technologies

* **Microsoft Power BI:** Dashboard development and visualization.
* **MySQL:** Data storage, querying, and analysis, if applicable.
* **SQL:** Data extraction and analysis, if applicable.
* **Python:** Exploratory data analysis, if applicable.

## 📊 Dashboard Highlights

The dashboard focuses on important banking metrics, including:

* Total Customers
* Total Bank Loans
* Total Bank Deposits
* Total Business Lending
* Total Savings Accounts
* Total Checking Accounts
* Foreign Currency Accounts
* Credit Card Metrics
* Customer Income Analysis
* Customer Segmentation

The exact metrics and visualizations depend on the final dashboard implementation.
